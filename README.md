# MuxedDrop

A lightweight YouTube client

## Built with:

- **Expo**: Cross-platform React Native framework
- **Uniwind**: Tailwind-like UI styling
- **YouTube.js**: YouTube API without login requirements

## Delegate:

- Stream URLs can be fetched from a custom server by setting `SERVER_URL`
